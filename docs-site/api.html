Restaurants

GET/api/v1/restaurants

Optional query: cuisine (case-insensitive), open=true, q (name contains). Response: { total, data }.

GET/api/v1/restaurants/:id

One restaurant. 404 if missing.

POST/api/v1/restaurants

{ "name": "Burger Hub", "cuisine": "american", "deliveryFee": 18, "isOpen": true }

name and cuisine required; deliveryFee (default 0) and isOpen (default true) optional. Returns 201.

PATCH/api/v1/restaurants/:id

{ "isOpen": false }

Send any of name, cuisine, deliveryFee, isOpen (at least one). Only the fields you send change.

DELETE/api/v1/restaurants/:id

Deletes the restaurant and its menu. Returns 204. Returns 409 if the restaurant already has orders.

Menu

GET/api/v1/restaurants/:id/menu

Available menu items. Response: { data }. 404 if the restaurant is missing.

POST/api/v1/restaurants/:id/menu

{ "name": "Falafel Wrap", "price": 35, "isAvailable": true }

Adds a dish. name and price required. Returns 201.

PATCH/api/v1/menu-items/:id

{ "price": 50, "isAvailable": false }

Change name, price or isAvailable (mark sold out). Old orders keep the price they were placed with.

Orders

GET/api/v1/orders

Lists orders, newest first. Optional query: status, restaurantId, limit (default 20, max 100), offset (default 0).

Response: { total, limit, offset, data }, where total counts all matches (for page buttons).

POST/api/v1/orders

Places an order at an open restaurant. Prices are calculated by the API, never taken from the client.

{
  "restaurantId": 1,
  "customerName": "Sara",
  "address": "12 Tahrir St, Giza",
  "items": [ { "menuItemId": 1, "quantity": 2 }, { "menuItemId": 3, "quantity": 1 } ]
}

201 with the created order. 400 for validation errors, closed restaurant or unavailable items. 404 if the restaurant is missing.

GET/api/v1/orders/:id

Order with its items. 404 if missing.

PATCH/api/v1/orders/:id/status

{ "status": "preparing" }

Only valid transitions are allowed (see the state diagram on the architecture page). An invalid move returns 409 with the allowed statuses.

POST/api/v1/orders/:id/cancel

Cancels an order (no body). Same rules as status changes: only pending or preparing orders can be cancelled, otherwise 409.
